# Personalized-diet-planner

**NutriPlan**: personalized nutrition and diet planning for every stage of life, starting with Bangladesh (English and Bangla).

| Folder | What it is |
|---|---|
| [`docs/prd/`](docs/prd/) | Product Requirements Document, the source of truth for features. Release phases are defined in [§43](docs/prd/03-release-phases-roadmap.md). |
| [`prototype/`](prototype/) | Clickable, installable PWA prototype (Next.js, Tailwind, shadcn/ui) for stakeholder review. See its [README](prototype/README.md). |
| [`prototype/UI-SPEC.md`](prototype/UI-SPEC.md) | UI specification for the production app (Flutter or React Native) to reproduce. |
| [`CLAUDE.md`](CLAUDE.md) | Project rules and context for AI-assisted development. |

```bash
cd prototype && npm install && npm run dev
```
